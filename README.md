Esta aplicación integra ejercicios de listas, NumPy, Pandas, llamadas a funciones de un módulo externo y operaciones CRUD , todo esto en una sola interfaz con navegación lateral.

**NumPy** — Guardar columnas de números (productos)  
**Streamlit** — La librería que pinta esta página web desde Python
